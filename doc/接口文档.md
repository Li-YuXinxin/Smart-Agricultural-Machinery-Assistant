## 接口文档

### 1. 系统总览

- **项目名称**：智慧农技助手  
- **版本**：v1.0  
- **基础路径**：`http://localhost:8001`（开发环境）  
- **数据格式**：JSON（请求/响应）  
- **说明**：当前阶段为框架搭建与功能验证，部分测试接口返回格式未完全统一，后续正式业务接口将遵循标准响应结构。

---

### 2. 通用响应格式（建议标准）

所有正式业务接口建议统一返回如下JSON结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 参数名    | 类型   | 说明                       |
| --------- | ------ | -------------------------- |
| `code`    | int    | 状态码，200 表示成功       |
| `message` | string | 提示信息                   |
| `data`    | object | 业务数据（各接口结构不同） |

### 4. 正式接口

#### 4.1 获取模型统计信息（`/api/classify/stats`）

**用途**：获取当前图像分类模型的统计信息，包括可识别品种数量、是否经过微调、品种名称列表。前端首页和识花页面使用此接口展示模型状态。

##### 4.1.1 基本信息
- **请求路径**：`/api/classify/stats`
- **请求方式**：`GET`
- **接口描述**：查询当前加载的分类模型信息，若模型经过微调则返回具体的植物品种名称列表。

##### 4.1.2 请求参数
无

##### 4.1.3 响应数据
- **格式**：`application/json`
- **参数说明**：

| 参数名         | 类型    | 说明                                         |
| -------------- | ------- | -------------------------------------------- |
| `count`        | int     | 可识别的类别总数                             |
| `is_finetuned` | boolean | 是否经过微调（true=植物品种，false=通用物品） |
| `class_names`  | array   | 品种名称列表（未微调时为空数组）             |

- **响应示例**（已微调）：
```json
{
  "count": 5,
  "is_finetuned": true,
  "class_names": ["玫瑰", "向日葵", "郁金香", "百合", "兰花"]
}
```

- **响应示例**（未微调）：
```json
{
  "count": 1000,
  "is_finetuned": false,
  "class_names": []
}
```

#### 4.2 图像分类识别（`/api/classify/`）

**用途**：上传花卉图片进行智能识别，返回 Top-5 预测结果及置信度。是拍照识花功能的核心接口。

##### 4.2.1 基本信息
- **请求路径**：`/api/classify/`
- **请求方式**：`POST`
- **Content-Type**：`application/json`
- **接口描述**：接收 Base64 编码的图片数据，调用 ResNet-50 模型进行分类预测，返回识别结果。

##### 4.2.2 请求参数

| 参数名  | 类型   | 必填 | 说明                                                       |
| ------- | ------ | ---- | ---------------------------------------------------------- |
| `image` | string | 是   | Base64 编码的图片数据，支持带 `data:image/xxx;base64,` 前缀 |

- **请求示例**：
```json
{
  "image": "data:image/jpeg;base64,/9j/4AAQSkZJRg..."
}
```

##### 4.2.3 响应数据
- **格式**：`application/json`
- **参数说明**：

| 参数名            | 类型   | 说明                                   |
| ----------------- | ------ | -------------------------------------- |
| `top1`            | string | 最可能的识别结果                       |
| `top1_confidence` | float  | 最高置信度（0~1），低于阈值时为 0      |
| `top5`            | array  | Top-5 候选列表，每项含 `class` 和 `confidence` |

- **响应示例**（识别成功）：
```json
{
  "top1": "玫瑰",
  "top1_confidence": 0.92,
  "top5": [
    {"class": "玫瑰", "confidence": 0.92},
    {"class": "月季", "confidence": 0.05},
    {"class": "牡丹", "confidence": 0.02},
    {"class": "蔷薇", "confidence": 0.008},
    {"class": "茶花", "confidence": 0.002}
  ]
}
```

- **响应示例**（置信度过低）：
```json
{
  "top1": "未知类型",
  "top1_confidence": 0.0,
  "top5": []
}
```

#### 4.3 获取训练状态（`/api/train/status`）

**用途**：查询当前模型训练任务的状态信息，包括训练进度（当前轮次/总轮次）。前端用于 HTTP 轮询兜底。

##### 4.3.1 基本信息
- **请求路径**：`/api/train/status`
- **请求方式**：`GET`
- **接口描述**：返回当前训练任务的状态、进度和结果。

##### 4.3.2 请求参数
无

##### 4.3.3 响应数据
- **格式**：`application/json`
- **参数说明**：

| 参数名           | 类型   | 说明                                                       |
| ---------------- | ------ | ---------------------------------------------------------- |

```json
}
```

#### 4.4 提交微调任务（`/api/train/finetune`）

**用途**：上传花卉图片和分类标签，启动 ResNet-50 模型的在线微调训练。是训练新品种功能的核心接口。

##### 4.4.1 基本信息
- **请求路径**：`/api/train/finetune`
- **请求方式**：`POST`
- **Content-Type**：`application/json`
- **接口描述**：接收 Base64 编码的图片数组和分类标签，保存图片到训练目录后启动后台微调任务。

##### 4.4.2 请求参数

| 参数名    | 类型    | 必填 | 说明                                         |
| --------- | ------- | ---- | -------------------------------------------- |
| `images`  | array   | 是   | Base64 编码的图片数组，每项为 `data:image/xxx;base64,...` 格式 |
| `label`   | string  | 是   | 分类标签名称（如"玫瑰"、"绿萝"）             |
| `clearOld`| boolean | 否   | 是否清除已有训练数据重新训练，默认 `false`   |

- **请求示例**：
```json
{
  "images": [
    "data:image/jpeg;base64,/9j/4AAQ...",
    "data:image/jpeg;base64,/9j/4AAQ..."
  ],
  "label": "绿萝",
  "clearOld": false
}
```

##### 4.4.3 响应数据
- **格式**：`application/json`
- **参数说明**：

| 参数名    | 类型   | 说明               |
| --------- | ------ | ------------------ |
| `message` | string | 提示信息           |
| `status`  | string | 当前训练状态       |

- **响应示例**（成功启动）：
```json
{
  "message": "训练已启动",
  "status": "running"
}
```

- **错误响应**（409 训练已运行）：
```json
{
  "detail": "正在运行中或者启动训练失败"
}
```

#### 4.11 AI 养护顾问问答（`/api/chat/stream`）

**用途**：向 AI 养护顾问提问，基于 RAG 知识库检索相关文档后由 LLM 生成回答，采用 SSE 流式输出。

##### 4.11.1 基本信息
- **请求路径**：`/api/chat/stream`
- **请求方式**：`POST`
- **Content-Type**：`application/json`
- **接口描述**：接收用户问题，先从 ChromaDB 向量库检索相关文档片段，拼接为上下文后调用 Qwen2.5 LLM 生成回答。采用 Server-Sent Events 格式流式返回。

##### 4.11.2 请求参数

| 参数名        | 类型   | 必填 | 默认值 | 说明               |
| ------------- | ------ | ---- | ------ | ------------------ |
| `message`     | string | 是   | -      | 用户提出的问题     |
| `temperature` | float  | 否   | 0.7    | 生成温度，越高越随机 |
| `max_tokens`  | int    | 否   | 512    | 最大生成 token 数  |

- **请求示例**：
```json
{
  "message": "绿萝叶子发黄怎么办？",
  "temperature": 0.7,
  "max_tokens": 512
}
```

##### 4.11.3 响应数据
- **格式**：`text/event-stream`（SSE）
- **数据格式**：每条消息以 `data:` 前缀开头，JSON 格式，以 `\n` 分隔。

| 参数名   | 类型    | 说明                                           |
| -------- | ------- | ---------------------------------------------- |
| `chunk`  | string  | 本次返回的文本片段（拼接后为完整回答）         |
| `done`   | boolean | 是否传输完成（`true` 时表示回答结束）          |
| `error`  | string  | 错误信息（仅出错时出现）                       |

- **响应示例**：
```
data:{"chunk":"绿萝叶子发黄可能有以下原因：\n1. 浇水过多...","done":false}

data:{"chunk":"2. 光照不足...\n来源文档: 绿萝养护指南.pdf","done":false}

data:{"chunk":"","done":true}
```

- **说明**：
  - 回答末尾可能附带 `来源文档:` 标记，列出检索到的知识库文件名
  - 若知识库中无相关内容，LLM 会基于通用知识回答并标注"未使用本地知识库"
  - 前端需自行拼接所有 `chunk` 字段得到完整回答
