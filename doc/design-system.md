# 🌿 植物养护助手 — 设计系统

> Style: **Organic Biophilic（自然有机）**
> Generated by UI/UX Pro Max v2.15.0
> 平台: 微信小程序（Skyline 渲染引擎）

---

## 一、设计理念

以**森林、阳光、土壤**为灵感，营造一个温暖、专业、值得信赖的植物养护空间。

| 关键词 | 表达方式 |
|--------|----------|
| 自然 | 大量绿色系、有机圆角、柔和阴影 |
| 温暖 | 琥珀色强调、圆润按钮、舒适间距 |
| 专业 | 清晰层级、语义色彩、一致间距 |
| 生命力 | 渐变背景、流动感圆角、呼吸感留白 |

## 四、间距系统

基于 **8rpx 网格**，保证视觉一致性：

```
space-1   8rpx    ← 微间距：图标与文字
space-2   12rpx   ← 小间距：列表项内
space-3   16rpx   ← 紧凑间距：组件内边距
space-4   24rpx   ← 标准间距：卡片内边距
space-5   32rpx   ← 页面左右边距
space-6   40rpx   ← 区块间距
space-7   48rpx   ← 大区块间距
space-8   64rpx   ← 页面顶部留白
space-9   80rpx   ← 大标题下方
space-10  96rpx   ← Hero 区域留白
```

## 八、图标规范

- **风格**：线条型（Phosphor / Lucide），统一 2px 描边
- **颜色**：继承 `currentColor`，跟随文字颜色
- **底部导航尺寸**：48rpx
- **行内图标**：32rpx，与文字垂直居中
- **禁止**：使用 Emoji 代替图标

---

## 九、动效规范

| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮点击反馈 | 150ms | standard |
| 页面切换 | 250ms | decelerate |
| 弹窗出现 | 250ms | decelerate |
| 弹窗消失 | 150ms | accelerate |
| 列表加载 | 400ms | decelerate |

**要点**：
- 按钮/卡片点击使用 `opacity: 0.85` 或 `scale(0.97)` 反馈
- 列表项交错入场，每项延迟 50ms
- 尊重 `prefers-reduced-motion`

## 快速使用示例

```css
/* 在页面 wxss 中直接使用变量 */
.my-card {
  background: var(--color-surface);
  border-radius: var(--radius-lg);
  padding: var(--space-4);
  box-shadow: var(--shadow-sm);
}

.my-title {
  font-size: var(--text-xl);
  font-weight: var(--weight-bold);
  color: var(--color-on-surface);
}

.my-btn {
  @apply btn-primary;  /* 或直接使用 utilities.wxss 中的类 */
}
```

```xml
<!-- 在 wxml 中使用工具类 -->
<view class="card">
  <text class="text-heading" style="font-size: var(--text-xl)">
    我的植物
  </text>
  <view class="btn-primary" style="margin-top: var(--space-4)">
    添加植物
  </view>
</view>
```
